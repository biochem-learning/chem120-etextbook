# Earlier implementations

These files are preserved for content comparison. The active app uses `src/views` and `src/components/content`; it does not import this archive.

- `src_components_Unit 1`, `Unit 2`, and `Unit 3` contain embedded lesson drafts.
- `src_components_Unit 4` is the earlier JSON renderer, despite its unit-specific name.
- `src_components_Home + Credit` contains the earlier home and credits pages.
- `src_components_common.js` and `src_components_style.css` supported the earlier slide layout.
- `latest` is a separate, unused Vite starter.

The earlier Unit 2 and Unit 3 topic order differs from the current JSON units. Existing JSON was the active sidebar source before cleanup, so it remains the published content. Keep this archive until a course editor has compared the earlier drafts with the published JSON and decided whether any extra explanations or exercises belong in the lessons.
