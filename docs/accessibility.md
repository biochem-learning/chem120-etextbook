# Accessibility review

The shared reader uses native links and buttons, semantic headings, labelled response fields, a document language, visible keyboard focus, and a layout that reflows at 320 px. The JSON format supports image alternatives, iframe titles, caption tracks, transcripts, and text descriptions for models. The 3D model also has keyboard rotation and zoom controls and a downloadable molecule file.

A local Chromium audit with axe-core 4.10.3 found zero WCAG A/AA rule violations across published Units 1–10. Browser checks also passed navigation, the legacy redirect, local image URLs, model controls, and 320 px reflow. The original lesson wording and content blocks are preserved. Automated checks of the reader do not prove full WCAG conformance.

The content validator reports 11 remaining editorial accessibility items. Published Unit 1's podcast and two videos need verified transcripts, captions, or an equivalent visual description as appropriate. [The podcast publisher's episode page](https://www.storycollider.org/stories/2016/1/4/deena-walker-just-like-my-sister) has a short summary but no full transcript. The ethanol 2D/3D video has an audio track. Draft Units 11 and 12 contain demonstration media and incomplete table/model descriptions; keep them in draft until completed.

Published YouTube videos and the Isomer Game resolve to active external pages. Their caption and keyboard behavior inside third-party frames still needs direct review. Chemistry figure alternatives derived from original captions need instructor accuracy review. A final WCAG 2.2 AA review should include keyboard-only and screen-reader sessions, zoom/reflow, and the real hosted resources.
